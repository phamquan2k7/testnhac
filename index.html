Hàng chờ

    Chưa có bài nào trong hàng chờ. Bấm vào một bài hát để bắt đầu.

    Thịnh hành trên Audius

    Nguồn: Audius — kho nhạc mở của nghệ sĩ độc lập, phát trọn bài chứ không phải bản thử 30 giây, không cần tài khoản.

    Dán link YouTube — không cần API key

    Chưa có API key? Dán link từ YouTube vào đây là nghe được ngay, không cần key.

    Chấp nhận mọi dạng link: youtube.com/watch?v=…, youtu.be/…, youtube.com/shorts/…, youtube.com/embed/… — dán bao nhiêu link thì bấy nhiêu bài vào hàng chờ, phát trọn bài qua deck bên trái.

    YouTube API key của bạn

    Key chỉ lưu trong trình duyệt này (localStorage) và chỉ được gửi tới www.googleapis.com khi bạn tìm kiếm — không qua bất kỳ máy chủ nào khác.

    Nhạc YouTube

    Nguồn: YouTube — phát trọn bài qua YouTube IFrame Player. Tìm kiếm cần API key của riêng bạn (key miễn phí cho khoảng 100 lượt tìm kiếm mỗi ngày); dán link thì nghe ngay, không cần key.

    Nguồn nhạc & ảnh bìa: YouTube (nghe full bài — dán link không cần key, tìm kiếm bằng API key của riêng bạn) và Audius API (nghe full bài, không cần tài khoản). Đúng chất “semi”: nhẹ tênh, không quảng cáo.
